# Usage Guide

Detailed guide on how to use and configure Telegram Chat Summarizer.

## Basic Usage

### Simple Run

```bash
# Use default settings from .env
python3 summarize.py
```

This will:
- Use `DEFAULT_DAYS` from your `.env`
- Summarize all chats listed in `CHATS`
- Save to `summaries/` directory
- Send to your Telegram Saved Messages

### Specify Days

```bash
# Last 7 days
python3 summarize.py --days 7

# Last 14 days
python3 summarize.py --days 14

# Last 30 days (monthly summary)
python3 summarize.py --days 30
```

### Help

```bash
python3 summarize.py --help
```

## Configuration

All configuration is done through the `.env` file.

### Chat Selection

```bash
# Single chat
CHATS=GO-DE-an

# Multiple chats (comma-separated)
CHATS=GO-DE-an,Alert DE Pipeline,Multidim inhouse

# Many chats
CHATS=Work Team,Weekend Plans,Family Group,Book Club,Gym Buddies
```

**Notes:**
- Chat names are **case-insensitive** (`go-de-an` works too)
- Must match the exact display name in your Telegram
- Spaces are allowed
- No quotes needed
- Use commas to separate

### Default Time Range

```bash
# Look back 7 days by default
DEFAULT_DAYS=7

# Or 14 days for bi-weekly
DEFAULT_DAYS=14

# Or 30 days for monthly
DEFAULT_DAYS=30
```

This is used when you run without `--days` argument.

### Agent Configuration

```bash
# Your Claude managed agent ID
CMA_AGENT_ID=agent_01PokRXVsswBTo8pBr2Scd1U

# Optional: Reuse the same environment
CMA_ENVIRONMENT_ID=env_01AbCdEfGh
```

**Environment ID**: After first run, copy the printed environment ID to your `.env` to avoid creating new environments each time.

## Output

### Local Files

Summaries are saved to `summaries/` with this naming:
```
summaries/
├── 2026-08-23_GO-DE-an.md
├── 2026-08-23_Alert_DE_Pipeline.md
└── 2026-08-23_Multidim_inhouse.md
```

**Format**: `YYYY-MM-DD_Chat_Name.md`

Each file contains:
```markdown
# GO-DE-an - Summary

**Period:** Last 7 days  
**Generated:** 2026-08-23 14:30:00

---

[Summary content here]

---

*Generated by Telegram Summarizer using Claude Agent*
```

### Telegram

Each summary is also sent to your **Saved Messages** with this format:

```
📊 **Summary: GO-DE-an**

[Summary content]
```

## Automation

### macOS/Linux: Cron

Add to your crontab:

```bash
# Edit crontab
crontab -e

# Add this line for weekly Monday 9am run
0 9 * * 1 cd /path/to/telegram-summarizer && /path/to/.venv/bin/python3 summarize.py --days 7

# Or monthly on 1st of month
0 9 1 * * cd /path/to/telegram-summarizer && /path/to/.venv/bin/python3 summarize.py --days 30
```

### macOS: Launchd

Create `~/Library/LaunchAgents/com.user.telegram-summarizer.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.user.telegram-summarizer</string>
    <key>ProgramArguments</key>
    <array>
        <string>/path/to/.venv/bin/python3</string>
        <string>/path/to/telegram-summarizer/summarize.py</string>
        <string>--days</string>
        <string>7</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/path/to/telegram-summarizer</string>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Weekday</key>
        <integer>1</integer>
        <key>Hour</key>
        <integer>9</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    <key>StandardOutPath</key>
    <string>/tmp/telegram-summarizer.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/telegram-summarizer.err</string>
</dict>
</plist>
```

Load it:
```bash
launchctl load ~/Library/LaunchAgents/com.user.telegram-summarizer.plist
```

### Windows: Task Scheduler

1. Open Task Scheduler
2. Create Basic Task
3. Name: "Telegram Summarizer"
4. Trigger: Weekly, Monday, 9:00 AM
5. Action: Start a program
   - Program: `C:\path\to\.venv\Scripts\python.exe`
   - Arguments: `summarize.py --days 7`
   - Start in: `C:\path\to\telegram-summarizer`
6. Finish

## Advanced Usage

### Debugging

Run with verbose output:

```bash
python3 -u summarize.py --days 7
```

The `-u` flag disables buffering so you see output immediately.

### Testing with Fewer Messages

To test quickly, use fewer days:

```bash
python3 summarize.py --days 1
```

### Checking Chat Names

If unsure about exact chat names, you can list your Telegram dialogs:

```python
# Create a quick script: list_chats.py
import asyncio
from telethon import TelegramClient
import os
from dotenv import load_dotenv

load_dotenv()
API_ID = int(os.getenv("TG_API_ID"))
API_HASH = os.getenv("TG_API_HASH")

async def main():
    async with TelegramClient("list_chats", API_ID, API_HASH) as client:
        print("Your Telegram chats:")
        print("-" * 60)
        async for dialog in client.iter_dialogs():
            print(f"  • {dialog.name}")

asyncio.run(main())
```

Run it:
```bash
python3 list_chats.py
```

## Output Management

### Viewing Summaries

```bash
# List all summaries
ls -lh summaries/

# View a specific summary
cat summaries/2026-08-23_GO-DE-an.md

# Or open in your editor
open summaries/2026-08-23_GO-DE-an.md
code summaries/2026-08-23_GO-DE-an.md
```

### Organizing Summaries

```bash
# Create monthly folders
mkdir -p summaries/2026-08
mv summaries/2026-08-*.md summaries/2026-08/

# Archive old summaries
tar -czf summaries-2026-08.tar.gz summaries/2026-08/
```

### Cleaning Up

```bash
# Delete summaries older than 90 days
find summaries/ -name "*.md" -mtime +90 -delete

# Or move to archive
mkdir -p archive
find summaries/ -name "*.md" -mtime +90 -exec mv {} archive/ \;
```

## Customization

### Changing Summary Style

The summary style is controlled by your Claude managed agent's system prompt. To change it:

1. Go to https://console.anthropic.com/agents
2. Edit your agent
3. Modify the system prompt
4. No code changes needed!

### Custom Prompts

The script sends this context to the agent:
```
Here are the text messages from the Telegram chat '{chat_name}'
from the last {days} days ({count} messages total), oldest first.
Each message is prefixed with a timestamp.

Please categorize and summarize these messages according to your system prompt.
Use icons (like 📌 🔔 ✅ 💡 ⚠️) instead of dashes for bullet points.

Messages:
[timestamp] message text
...
```

The agent uses its configured system prompt to generate the summary.

## Troubleshooting

### No Messages Found

```
⚠️ No messages found in the last 7 days
```

**Causes:**
- Chat was inactive during that period
- You weren't a member yet
- Messages were deleted

**Solutions:**
- Increase days: `--days 14`
- Check if you're actually in that chat
- Verify chat name is correct

### Chat Not Found

```
❌ Could not find chat "xyz"
```

**Solutions:**
- Check exact spelling in Telegram
- Use `list_chats.py` to see available chats
- Make sure you're a member of the chat

### Rate Limiting

If you're summarizing many chats or long periods:
- Anthropic API has rate limits
- Script automatically handles this
- Just be patient, it will complete

### Session Expired

If you get authentication errors:
```bash
# Delete session and re-login
rm multidim_summary.session*
python3 summarize.py
```

## Best Practices

1. **Weekly cadence**: Run weekly for best results

3. **Review summaries**: Check local files for quality

5. **Archive old summaries**: Keep `summaries/` manageable
6. **Backup session**: Keep `.session` file backed up
7. **Update .env**: Save environment ID after first run
