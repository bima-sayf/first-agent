## ✨ Key Features

### 1. Time-Based Fetching
- Fetch messages from last N days (not just N messages)
- More accurate for weekly/monthly catch-ups
- Configurable via CLI: `--days 7`

### 2. Clean Configuration
All settings in `.env`:
```bash
CHATS=GO-DE-an,Alert DE,Multidim
DEFAULT_DAYS=7
TG_API_ID=...
TG_API_HASH=...
ANTHROPIC_API_KEY=...
CMA_AGENT_ID=agent_01...
```

### 3. Dual Output
- **Local files**: Markdown files in `summaries/`
- **Telegram**: Sent to your Saved Messages

### 4. Icon-Based Formatting
Summary uses icons (📌 ✅ ⚠️) instead of dashes for better readability.

### 5. Proper Markdown Structure
Local files have clean markdown with:
- Title and subtitle
- Metadata (period, timestamp)
- Formatted content
- Footer

## 🚀 How to Use

### First Time Setup

```bash
# 1. Configure
cp .env.example .env
nano .env  # Fill in your credentials

# 2. Install
pip install -r requirements.txt

# 3. Run (first time asks for phone verification)
python3 summarize.py
```

### Regular Use

```bash
# Weekly catch-up (uses DEFAULT_DAYS from .env)
python3 summarize.py

# Specify days
python3 summarize.py --days 14

# After vacation
python3 summarize.py --days 30
```

## 🔧 Technical Details

### Dependencies
- `telethon==1.36.0` - Telegram client
- `anthropic==0.40.0` - Claude API
- `python-dotenv==1.0.1` - Environment config

### Session Management
- Session file: `multidim_summary.session`
- Created on first run
- Reused for subsequent runs
- Keep private (equivalent to Telegram login)

### Environment Management
- Claude environment created on first run
- Prints ID to save in `.env`
- Reuses environment for efficiency

### Time-Based Filtering
- Uses Telethon's `offset_date` parameter
- Fetches messages up to N days ago
- More accurate than message count for periodic summaries
